Live XDP test on Azure

One click builds two Azure VMs: a shop behind LimitPlane with the eBPF fast path, and an attacker. The attacker floods it and forges another visitor's address, gets banned, and is dropped in the kernel. Then both VMs are deleted.

Replay Showing the recorded run from 22 Oct 2026. GitHub Actions
Press Run to start a real test on Azure. It takes about 6 minutes.

Attacker. A second VM sends requests as fast as it can and lies about who it is (a fake X-Forwarded-For). Green got through, amber was rate limited, red got no answer at all.

Kernel. LimitPlane bans the attacker, and within a second the ban is copied into the network card's eBPF program. From then on its packets are dropped before Linux or the app see them.

Normal visitor. The address the attacker pretended to be. It keeps getting the shop the whole time, which shows the fake header did not work.
