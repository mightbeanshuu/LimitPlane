Rate limiting that knows
what AI actually costs

A ping costs microseconds. An AI inference call costs real GPU money. LimitPlane is a drop-in layer that prices every request by its AI cost class and budgets it per tenant, tier, and route, before it touches your servers.

Any site. A few steps. No rewrites.

Two ways in: run the proxy in front of anything (Python, PHP, Rails, even a static site; it never knows the layer is there), or import the middleware if you're on Node.

1

One command. Protected.

No install, no clone, no config. Point it at your site and send traffic to port 3000. Every visitor gets 60 requests/minute out of the box.

npx github:mightbeanshuu/LimitPlane --upstream http://localhost:8080
2

Price your AI routes with flags

Mark expensive endpoints heavy (5 tokens each) and tune the per-visitor budget.

npx github:mightbeanshuu/LimitPlane --upstream http://localhost:8080 \
  --rpm 120 --heavy /api/ai-scan,/api/generate
3

Go multi-tenant when you're ready

A config file adds tiers, API keys, and per-customer budgets. Blocked requests get a clean 429 + Retry-After and never reach your servers.

cp limitplane.config.example.json limitplane.config.json
node bin/limitplane.js --config limitplane.config.json

1

Install straight from GitHub

npm install github:mightbeanshuu/LimitPlane
2

Create the layer with your policy

import { createLimitPlane } from "limitplane";

const lp = createLimitPlane({ policy: {
  tiers:  { free: { capacity: 10, refillPerSecond: 1 },
            pro:  { capacity: 50, refillPerSecond: 5 } },
  routes: { "/v1/scan": { costClass: "heavy" },  // AI inference: 5 tokens
            "*":        { costClass: "light" } }, // everything else: 1
  tenants:{ "customer-key": { tenantId: "acme", tier: "pro" } },
}});
3

How it works

Five steps, one decision, fully audited

Every request runs the same pipeline. Every verdict, allowed or blocked, is written to an audit log with the facts, so “why was acme blocked at 14:32?” has a real answer.

            ┌───────────────────────────────────────────────────┐
 request ──▶│                 LIMITPLANE LAYER                  │──▶ your site
            │                                                   │
            │  1 WHO?    x-api-key → tenant + tier              │
            │            (unknown keys → anon free tier by IP)  │
            │  2 WHAT?   route → cost class                     │
            │            light 1 · standard 2 · heavy 5 tokens    │
            │  3 CHECK   token bucket per tenant:tier:route     │
            │  4 TELL    X-RateLimit-* headers on every reply   │
            │  5 VERDICT pass through, or 429 + Retry-After    │
            │            + a reason that explains itself        │
            │                    ▼                              │
            │              audit log (facts, not guesses)       │
            └───────────────────────────────────────────────────┘
Cost classes

Heavy requests pay more. Cheap traffic keeps flowing.

One shared budget per tenant per route, but AI-priced. A free tier with 10 tokens gets 10 pings or exactly 2 model inferences. Expensive traffic hits its ceiling first, so it can never starve the cheap stuff.

light
1 token

Pings & reads

Health checks, metadata, anything your servers barely notice.

standard
2 tokens

Normal API work

Typical CRUD and business logic: the everyday traffic.

heavy
5 tokens

AI inference

NSFW/content scans, GenAI calls: the requests that cost real GPU money.

Under the hood

Small, honest engineering

Built as a learning-grade codebase you can actually read: every file is commented like a lesson.

7 limiter algorithms

Fixed window, sliding log & counter, token bucket, leaky bucket, plus two distributed Redis variants, all from scratch and all tested.

Atomic under fire

The Redis Lua limiter does INCR + EXPIRE in one atomic round trip. Benchmarked at 181k checks/sec across 50 tenants at concurrency 100.

Tenant isolation

Buckets are keyed tenant:tier:route. One customer burning their budget mathematically cannot touch anyone else's.

Zero dependencies

The layer and proxy run on plain node:http. Redis is optional, only when you scale past one server.

Deterministic tests

Injectable clocks everywhere, so tests fast-forward time instead of sleeping. 14 unit tests cover allow, block, reset, and isolation.

Fails loudly

Unknown tiers or cost classes throw at config time. A policy typo explodes in dev instead of silently mis-limiting in prod.
