LimitPlane {{ .Chart.AppVersion }} is installed as release {{ .Release.Name }}.

Watch it come up:
  kubectl -n {{ .Release.Namespace }} rollout status deploy/{{ include "limitplane.fullname" . }}

Your rate limits are now Kubernetes objects:
  kubectl -n {{ .Release.Namespace }} get ratelimitpolicies
  kubectl -n {{ .Release.Namespace }} get tenants
  kubectl -n {{ .Release.Namespace }} describe rlp {{ .Values.rateLimitPolicy.name }}

Which replica writes status back (exactly one should hold the lease):
  kubectl -n {{ .Release.Namespace }} get lease limitplane-operator -o yaml

Open the dashboard:
  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "limitplane.fullname" . }} 3000:{{ .Values.service.port }}
  open http://localhost:3000/dashboard

Prometheus scrape:
  curl -s localhost:3000/metrics | grep limitplane_
